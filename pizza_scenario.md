# Сценарии использования для онлайн-пиццерии

## Пользовательские истории

### 1. Заказ пиццы
**Как:** пользователь  
**Я хочу:** выбрать один из пяти видов пиццы  
**Чтобы:** заказать её  

**Критерии приемки:**
- На сайте отображаются все доступные виды пиццы
- Пользователь может кликнуть на любой вид пиццы и увидеть его описание и цену
- Пользователь может добавить выбранную пиццу в корзину

---

### 2. Добавление топпингов
**Как:** пользователь  
**Я хочу:** добавлять топпинги к выбранной пицце  
**Чтобы:** настроить её по своему вкусу  

**Критерии приемки:**
- После выбора пиццы предлагается список доступных топпингов
- Можно выбрать один или несколько топпингов
- Цена пиццы обновляется в зависимости от выбранных топпингов

---

### 3. Выбор способа доставки
**Как:** пользователь  
**Я хочу:** выбрать способ доставки (домой или в офис)  
**Чтобы:** получить пиццу в удобное место  

**Критерии приемки:**
- На странице оформления есть опция выбора адреса доставки
- Пользователь может ввести адрес доставки

---

### 4. Оплата заказа
**Как:** пользователь  
**Я хочу:** оплатить заказ онлайн  
**Чтобы:** получить подтверждение и избежать оплаты наличными  

**Критерии приемки:**
- Имеется форма для ввода данных карты
- После оплаты отображается подтверждение заказа

---

## Основные сценарии использования

### 1. Заказ пиццы с топпингами
**Цель:** Заказать пиццу с дополнительными ингредиентами  
**Акторы:** Пользователь  

**Основной сценарий:**
1. Пользователь заходит на сайт
2. Выбирает вид пиццы
3. Добавляет топпинги
4. Добавляет пиццу в корзину
5. Переходит к оформлению заказа

**Альтернативный сценарий:**
- Если не хочет топпинги, может сразу перейти к оформлению

---

### 2. Выбор способа доставки
**Цель:** Выбрать способ доставки  
**Акторы:** Пользователь  

**Основной сценарий:**
1. Пользователь завершает выбор пиццы
2. Выбирает "доставка домой" или "в офис"
3. Если выбрана доставка - вводит адрес

**Исключения:**
- При недействительном адресе система показывает ошибку

---

### 3. Оплата заказа
**Цель:** Оплатить заказ  
**Акторы:** Пользователь  

**Основной сценарий:**
1. Пользователь вводит данные карты
2. Система проверяет данные и подтверждает оплату
3. Пользователь получает подтверждение

**Исключения:**
- При неверных данных карты система показывает ошибку

---

## Функциональные требования

### 1. Обработка заказа
Система должна позволять:
- Выбирать вид пиццы
- Добавлять топпинги
- Указывать адрес доставки

### 2. Обработка платежей
Система должна:
- Обрабатывать данные карты
- Подтверждать оплату
